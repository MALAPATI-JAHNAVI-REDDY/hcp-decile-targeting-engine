# Excel Dashboard Guide
### HCP Decile Targeting & Field Force Allocation Engine

This guide walks through building a self-service Excel dashboard on top of
`processed_hcp_targets.csv` (generated by `python/hcp_segmentation.py`).

---

## 1. Import the Data

1. Open a new Excel workbook.
2. Go to **Data** tab → **Get Data** → **From File** → **From Text/CSV**.
3. Select `processed_hcp_targets.csv`.
4. In the preview window, confirm delimiter = **Comma**, then click **Load**
   (or **Transform Data** if you want to rename/reorder columns first).
5. Confirm the table loads with these columns:
   `hcp_id, hcp_name, region, specialty, trx_count, nrx_count,
   trx_rank, nrx_rank, volume_tile, priority_tier, monthly_visit_target,
   nrx_to_trx_ratio`
6. Rename the loaded table to **`HCP_Targets`**
   (Table Design tab → Table Name box).

---

## 2. Build a Pivot Table: Specialty vs TRx

1. Click anywhere inside the `HCP_Targets` table.
2. Go to **Insert** → **PivotTable** → **New Worksheet**.
3. In the PivotTable Fields pane:
   - Drag **`specialty`** into **Rows**.
   - Drag **`priority_tier`** into **Rows** (below specialty, for drill-down).
   - Drag **`trx_count`** into **Values** → set to **Sum**.
   - Drag **`nrx_count`** into **Values** → set to **Sum**.
   - Drag **`hcp_id`** into **Values** → set to **Count** (renames to "Count of hcp_id" — this gives HCP count per specialty/tier).
4. Rename the sheet tab to **`Specialty_TRx_Pivot`**.
5. (Optional) Insert a **PivotChart** (Insert → PivotChart → Clustered Column)
   using the same field layout to visualize TRx by specialty.

---

## 3. Build a Second Pivot: Region Workload Summary

1. Insert a second PivotTable from the same `HCP_Targets` table.
2. Fields:
   - **Rows**: `region`
   - **Values**: Sum of `trx_count`, Sum of `monthly_visit_target`,
     Count of `hcp_id`
3. Add a calculated field for estimated reps needed:
   - PivotTable Analyze → **Fields, Items & Sets** → **Calculated Field**
   - Name: `Estimated_Reps_Needed`
   - Formula: `=monthly_visit_target/40`
4. Rename this sheet **`Regional_Workload_Pivot`**.
