# Excel Dashboard Guide
### HCP Decile Targeting & Field Force Allocation Engine

This guide walks through building a self-service Excel dashboard on top of
`processed_hcp_targets.csv` (generated by `python/hcp_segmentation.py`).

---

## 1. Import the Data

1. Open a new Excel workbook.
2. Go to **Data** tab → **Get Data** → **From File** → **From Text/CSV**.
3. Select `processed_hcp_targets.csv`.
4. In the preview window, confirm delimiter = **Comma**, then click **Load**
   (or **Transform Data** if you want to rename/reorder columns first).
5. Confirm the table loads with these columns:
   `hcp_id, hcp_name, region, specialty, trx_count, nrx_count,
   trx_rank, nrx_rank, volume_tile, priority_tier, monthly_visit_target,
   nrx_to_trx_ratio`
6. Rename the loaded table to **`HCP_Targets`**
   (Table Design tab → Table Name box).

---

## 2. Build a Pivot Table: Specialty vs TRx

1. Click anywhere inside the `HCP_Targets` table.
2. Go to **Insert** → **PivotTable** → **New Worksheet**.
3. In the PivotTable Fields pane:
   - Drag **`specialty`** into **Rows**.
   - Drag **`priority_tier`** into **Rows** (below specialty, for drill-down).
   - Drag **`trx_count`** into **Values** → set to **Sum**.
   - Drag **`nrx_count`** into **Values** → set to **Sum**.
   - Drag **`hcp_id`** into **Values** → set to **Count** (renames to "Count of hcp_id" — this gives HCP count per specialty/tier).
4. Rename the sheet tab to **`Specialty_TRx_Pivot`**.
5. (Optional) Insert a **PivotChart** (Insert → PivotChart → Clustered Column)
   using the same field layout to visualize TRx by specialty.

---

## 3. Build a Second Pivot: Region Workload Summary

1. Insert a second PivotTable from the same `HCP_Targets` table.
2. Fields:
   - **Rows**: `region`
   - **Values**: Sum of `trx_count`, Sum of `monthly_visit_target`,
     Count of `hcp_id`
3. Add a calculated field for estimated reps needed:
   - PivotTable Analyze → **Fields, Items & Sets** → **Calculated Field**
   - Name: `Estimated_Reps_Needed`
   - Formula: `=monthly_visit_target/40`
4. Rename this sheet **`Regional_Workload_Pivot`**.

---

## 4. Conditional Formatting for Tier 1 Target Doctors

Apply this directly on the raw `HCP_Targets` table (not the pivot):

1. Select the full data range of the table (e.g., `A2:L31`).
2. Go to **Home** → **Conditional Formatting** → **New Rule**.
3. Choose **"Use a formula to determine which cells to format."**
4. Enter the formula (adjust column letter to match your `priority_tier`
   column, e.g. column J): =$J2="Tier 1 - High Priority"
   5. Click **Format** → **Fill** tab → choose a highlight color (e.g., red/orange
   for high priority) → **OK** → **OK**.
6. Optional secondary rule for Tier 2 (yellow) and Tier 3 (green/grey), using
   the same formula pattern with each tier label.
7. To make Tier 1 rows stand out at a glance in the pivot table, also apply a
   **Data Bar** or **Icon Set** on the `monthly_visit_target` column.

---

## 5. Suggested Dashboard Layout

Create a final `Dashboard` sheet combining:
- **KPI cards** (top row): Total HCPs, Total TRx, Total Monthly Visits,
  Estimated Reps Needed — each linked via cell references to the pivot sheets.
- **Left panel**: Specialty vs TRx PivotChart.
- **Right panel**: Regional Workload PivotTable/Chart.
- **Bottom table**: Filtered view (using a Slicer on `priority_tier`) showing
  only Tier 1 HCPs and their assigned visit targets.

To add a slicer:
1. Click inside either PivotTable → **PivotTable Analyze** → **Insert Slicer**.
2. Check **`priority_tier`** → **OK**.
3. Right-click the slicer → **Report Connections** → connect it to both
   PivotTables so filtering one filters both.

---

## 6. Refreshing Data

Whenever `hcp_segmentation.py` is re-run and `processed_hcp_targets.csv` is
updated:
1. Go to **Data** tab → **Refresh All**.
2. All PivotTables, charts, and conditional formatting will update
   automatically since they're driven by the `HCP_Targets` table reference.
